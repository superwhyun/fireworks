# PYRO — 실시간 3D 불꽃놀이 스튜디오

Three.js 기반 실시간 3D 불꽃놀이 웹앱입니다. 스페이스바로 불꽃을 발사하고, 음악을 올리면 비트에 맞춰 자동으로 터집니다.

## 실행

```bash
npm install
npm run dev
```

빌드: `npm run build` → `dist/` (정적 파일, 어디서나 서빙 가능)

## 다른 기기(같은 네트워크)에서 접근

`vite.config.ts`에 `host: true`가 설정되어 있어 dev 서버가 모든 네트워크 인터페이스에 열립니다.

1. 서버 실행: `npm run dev` — 터미널에 `Local:`과 `Network:` 주소가 함께 표시됩니다.
2. 같은 Wi-Fi/LAN에 연결된 다른 기기의 브라우저에서 `Network:` 주소(`http://<이 PC의 LAN IP>:5173`)를 엽니다.
3. 접속이 안 되면 Windows 방화벽을 열어야 합니다. 저장소 루트의 **`allow-lan.bat`을 더블클릭**(UAC 승인)하면 5173/4173 인바운드 규칙이 자동 추가됩니다. 또는 관리자 PowerShell에서 `allow-lan.ps1`을 실행하세요.

LAN IP 확인: `Get-NetIPAddress -AddressFamily IPv4` (예: `192.168.0.13`)

빌드 결과를 다른 기기에서 서빙하려면 `npm run preview`도 같은 방식으로 `Network:` 주소를 사용합니다.

## 사용법

- **스페이스바**: 선택한 종류·팔레트로 불꽃 1발 발사 (구경·높이·연소 시간은 매번 무작위)
- **캔버스 클릭**: 클릭한 위치에서 터지도록 발사
- **배경**:
  - 강: 건너편 아파트 단지·업무지구 스카이라인, 차량이 달리는 양안 강변도로, 아치 다리 2개, 수면에 길게 번지는 건물 불빛 반사
  - 호수: 산 능선, 잔잔한 수면 / 바다: 큰 너울, 등대·배
  - 도심: 공원을 둘러싼 아파트 단지·업무지구, 순환로·방사형 대로, 앞쪽 고가 도시고속도로의 차량 행렬 (수면 없음)
  - 건물 파사드 4종(아파트·오피스·호텔·상가)마다 창 크기·배치·점등 습관이 다름. 아파트 계단실 형광등, 오피스 층 단위 점등, 상가 간판·네온, 옥상 크라운 조명·단지 사인, 항공장애등
  - 차량은 실제로 움직이며 전조등(흰색)·후미등(빨강)으로 표시. 지평선의 도시 광공해 글로우와 원경 산 능선
- **카메라**: 드래그 회전 · 휠 확대/축소 · 우클릭(또는 두 손가락) 드래그 이동
  - 시점 프리셋 `1` 정면 · `2` 근접 · `3` 수면 · `4` 조감 · `5` 측면
  - `R` 자동 회전 · `Enter` 전체 화면 · `H` UI 숨기기/보이기
- **자동 쇼**: 대형 단발, 좌우 대칭, 부채꼴, 좌→우 연발, 수직 다층, 혼합 일제 사격을 연출하고 16큐마다 피날레
- **피날레** (`F`): 약 6초간 밀집 연사 → 금색 카무로 캐노피 → 뇌성 마무리
- **불꽃 종류 (20종)**: 모란, 국화, 달리아, 버드나무, 카무로, 야자수, 고리, 토성, 하트, 별, 나선, 크로셋, 딱딱이, 점멸, 이중심, 변색, 물고기, 폭포, 다단, 뇌성
- **색상**: 실제 연화 발색제 기준(스트론튬 적색, 바륨 녹색, 구리 청색, 숯 금색, 마그네슘 은색 등). 한 발에 1~2색만 사용
- **규모**: 전체 폭발 크기·입자 밀도 배율
- **품질**: 절전 / 표준 / 최고 (입자 수 스케일)
- **설정 기억**: 배경·불꽃 종류·팔레트·규모·자동 쇼·품질·사운드·자동 회전을 이 브라우저에 저장해 다음 방문 때 복원 (기기별 저장, 서버로 전송하지 않음)

## 사실감 관련 구현

- 별(star)은 점이 아니라 속도 방향 **모션 블러 스트릭**으로 렌더 (눈의 잔상/사진 노출과 같은 효과)
- 꼬리 별은 불티를 연속 방출하며 잔불은 붉게 식으며 사라짐
- 셸마다 **구경**(소형~대형) 무작위, 큰 셸일수록 높이 올라가 크게 터짐. **연소 시간·확산 속도**도 셸마다 다름
- 폭발 섬광이 하늘과 연기를 비추고, 연기는 바람에 흘러감
- 수면: 여러 방향 파도를 합성한 물결 셰이더, 프레넬 반사, 폭발·달빛이 물결에 부서지는 반짝이는 빛길, 흔들리는 불꽃 반사상
- **사운드**: 오실레이터(음정 있는 파형)를 쓰지 않고, 폭발 압력파(N-wave)와 잡음으로 합성. 거리가 멀수록 고음이 깎이고 메아리 비중이 커짐. 종류별로 다른 소리:
  - 일반: 날카로운 파열음 + 저음 + 굉음 잔향
  - 뇌성: 매우 크고 날카로운 폭음
  - 딱딱이: 폭발 후 별이 꺼지면서 연쇄적으로 타닥타닥
  - 버드나무·카무로·폭포·비단: 둔중한 폭음 + 떨어지는 불티의 '쏴아' 소리
  - 점멸: 지글거림, 다단: 작은 연속 펑, 크로셋: 갈라질 때 딱 소리
  - 발사 시 박격포 '퉁' 소리와 상승하는 셸의 희미한 쉭 소리
  - 야외 메아리(컨볼루션 리버브), 화면 좌우 위치에 따른 스테레오, **거리에 따른 소리 지연**(빛이 먼저, 소리는 나중)

## 음악 연동

파일을 패널의 업로드 영역에 올리거나 화면 아무 곳에나 **드래그 앤 드롭**하세요.

지원 형식: **MP3, WAV, M4A/AAC, OGG, FLAC, OPUS**, 그리고 **MP4**(오디오 트랙이 있는 경우). 브라우저가 디코딩할 수 있는 형식이면 동작합니다. (MP4는 컨테이너 형식이라 오디오 코덱에 따라 재생 여부가 달라질 수 있습니다 — 가장 안전한 건 MP3와 WAV입니다.)

모드:
- **반응**: Web Audio AnalyserNode로 저역/중역 온셋(비트)을 감지해 그 순간 발사. 음량이 클수록 더 높이, 더 크게 터집니다.
- **자동**: 음악과 무관하게 연속 발사 (파티 모드).
- **정지**: 음악 반응 끔.

재생/일시정지, 구간 이동, 실시간 레벨 미터를 제공합니다.

## 사운드

발사 시 휘슬, 폭발 시 저음 붐 + 딱딱거리는 잔향을 Web Audio로 절차적 합성합니다 (외부 음원 불필요). 스피커 아이콘으로 끌 수 있습니다.

## 구조

- `src/fireworks/engine.ts` — 셸 비행, 20종 폭발 패턴, 입자 시뮬레이션(꼬리·분열·변색·점멸·딱딱이)
- `src/fireworks/particles.ts` — 입자 풀 + GLSL 포인트/모션 스트릭 + 수면 반사
- `src/fireworks/glow.ts` — 섬광·잔광 스프라이트, 연기
- `src/fireworks/patterns.ts` — 패턴 목록, 실제 발색 팔레트
- `src/fireworks/director.ts` — 렌더 루프, OrbitControls 카메라·프리셋, 쇼 연출/피날레, 음악 반응
- `src/fireworks/sound.ts` — 종류별 절차적 음향, 리버브·패닝·거리 지연, 음악 분석/온셋 검출
- `src/fireworks/stage.ts` — WebGL 렌더러 + ACES 톤매핑 + UnrealBloom
- `src/fireworks/environment.ts` — 하늘 돔(달, 섬광 조명), 별, 물결 수면 셰이더
- `src/fireworks/scenery.ts` — 배경 4종(강·호수·바다·도심) 구성
- `src/fireworks/urban.ts` — 도시 야경 도구: 파사드 텍스처 4종, 건물 셰이더(물결 반사 포함), 움직이는 차량, 도로·가로등, 항공장애등, 산 능선
